# tools/content-denylist.txt: names of real commercial works and their makers that must not appear in
# the published tree (tools/check-content.sh, ctest "tools_check_content"). Owner's rule: never upload
# any copyrighted content, and the tree must not even show such names as if they were shared files
# (demo data, tests, tools, documents, comments). Use invented names, public-domain works (a composer
# and a composition, a public-domain text) or freely licensed ones (the Blender open films, Linux
# distributions) instead.
#
# One entry per line, matched case-insensitively as whole words: a letter or digit right before or
# after the entry is no hit ("Queensland" is not "Queen"), an underscore, dot or dash is a separator
# ("Glenn_Miller_-_..." is a hit). Blanks, dots, dashes and underscores inside an entry match any run
# of them, or none ("Spider-Man" also finds "spiderman", "Spider Man", "spider_man"). Regular
# expression characters are taken literally. A justified hit goes into tools/content-allowlist.txt
# with its reason. This is a tripwire, not a database: add the name when you remove one.
